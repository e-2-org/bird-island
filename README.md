# Bird Island

## by Janice Kerbel

Part of _The Bird Island Project_ (2000–2002) in which Janic Kerbel addresses questions of ecology, tourism, surveillance, and urbanism.

The work began with Kerbel fantasizing about a paradise where she could holiday but ended up as a precise representation of a fictitious yet geologically possible atoll in the Bahamas. Ready for tourist development, the island is inhabited by the Exuma Emerald, a bird that’s utterly imaginary yet ecologically feasible - a point that Kerbel ensured by working with an ornithologist to determine how the bird might look and sound.

Ultimately, the project came to comprise a promotional text, this Internet site, various drawings and maps, and a CD of the mysterious Exuma Emerald’s calls.
